Best Learning Practice 不見得是 Best Practice

Posted by MingLun Allen Wu on Thursday, May 28, 2026

不急著找最完整的答案

我最近發現，自己在學習一件事情時，常有一種迷思： 「要學，就要從最完整、最齊全的 Best Practice 學起」。

例如前陣子對AI 工具感到焦慮 時，就是這樣。

一直有一種「該學、想學，但不知道從何開始」的感覺，於是在網路上尋找各種內容：XX 大神的 AI 工作法、熱門的框架、2026 年必須掌握的 3 種 Skill…我很快就被大量的術語、工具名稱給淹沒了。

我擔心自己只要一開始沒站在最正確的位置、沒有找到最完整的框架，學習就會不夠有效率。

不過最近在讀《User Story Mapping》中有一個觀點，打破了我既有的印象：

Best Learning Practice 並不一定要是 Best Practice

在很多學習情境裡，其實都不是真的「不知道怎麼學」，只是想找到一套最完整、最正確、最值得投入時間的學習方式。

這些內容很有價值，可能是某些人的 Best Practice，但對一個剛開始摸索的人來說，它們太「遠」了。

我沒有辦法吸收，也無法轉換成自己的東西。更直白的說，這些 “Best Practice” 對於減緩焦慮一點幫助都沒有。

學習初期需要的不是強度

我想分享自己剛開始接觸重訓時的經驗。

初期訓練常常只是拿一根空槓，反覆練習很基本的動作。

從增肌的角度來說，沒有任何重量，當然不是什麼有效的訓練菜單，顯然不是 Best Practice。

但對於剛開始學習的人來說，這是重要的 Best Learning Practice。

因為那個階段的重點並不在強度，而是能不能建立感覺。

它讓我可以先感覺動作，確認自己有沒有站穩。也因為重量還不重，所以有空間犯錯、有空間調整。

好的學習方法，不一定是最完整、最進階、最符合成熟實務的做法。

對初學者來說，真正重要的是：它能不能讓你開始理解？能不能讓你安全地犯錯？能不能讓你慢慢修正？

如果回過頭來思考，自己為什麼會習慣尋找 Best Practice，我覺得可能跟「完美主義」有點關係。

希望自己的產出夠好、希望投入的時間值得、希望每一次學習都不要浪費，久而久之，我開始用嚴格的標準來檢視「學習」這件事。

但當我把學習也當成一種要被評分的成果，就很容易在還沒開始前就被自己的標準卡住。

離自己近一點的學習材料

我很喜歡 Huli 在〈每一篇心得都有價值——為什麼初學者才更應該要寫心得筆記〉中分享的觀念：

最好，是更好的敵人

這句話放在學習裡也很適用。

對新手來說，看大神們的文章有時候收穫反而不是最多的。不是因為大神們寫得不好，而是距離太遠，裡面很多脈絡、判斷和取捨，都需要擁有大量經驗後才能體會到醍醐味。

反而是「新手的心得文」，對一個真正的新手來說，可能更有幫助。

記得自己在職涯初期也寫過一篇文章記錄初學者視角的珍貴 - 剛加入團隊的新人，可以做些什麼？。

以初學者的視角，去記錄哪些概念特別難懂，不一定是最完整、最精準，但更接近一個人剛開始理解事情時，真正走過的路。

我想，這就是 Best Learning Practice 很重要的一點：

它不一定是最強大的做法，但它要足夠靠近學習者當下的位置。

基礎不是低階的東西

當我們在培養專業技能時，常會希望能盡快達到「進階」的層級。

例如我剛接觸軟體工程領域時，總覺得只學基礎概念是不夠的，應該要趕快學會分散式運算、Asynchronous Programming…或是各種系統設計的概念。

這些主題看起來很龐大，也不容易找到一條快速通往進階的道路。

但 Andrew 在〈架構師觀點 - API Design Workshop〉談到「基礎理念」和「基礎技巧」的重要性，讓我對這件事有另一層理解：

基礎知識的價值，不只是讓你學會某個技能，而是讓你開始練習用正確的角度思考。

當你掌握了基本技術，後續遇到更大、更複雜的問題時，就不會只是覺得它們很陌生、很可怕。你會開始看見其中的結構，也能慢慢把問題拆回自己理解的部分。

換句話說，基礎不是比較低階的東西。

基礎是讓你有能力繼續往前學的東西。

這也讓我想到 〈20 Things I’ve Learned in my 20 Years as a Software Engineer〉 中作者分享的觀點：

身為軟體工程師，要學著接受一件事:
世界上不會有完美的 Solution、Test、Code 或 Architecture。

與其追求完美，不如追求一個 Livable System，讓系統能持續優化。

學習好像也是這樣，不需要一開始就找到最完整的 Best Practice。

很多時候，我們需要的是一個足夠貼近當前狀態的學習方式：它不一定漂亮，不一定完整，但它讓我們開始理解，也讓我們願意繼續走下去。

寫到這裡，也像是在提醒自己。

學習不需要一開始就把自己放到最正確、最棒的位置，而是先尋找一個適合自己、適合開始的位置。

只要能開始理解、開始犯錯、開始修正，那就已經是當下最適合自己的練習了。

謝謝你的閱讀，我們下次見。
